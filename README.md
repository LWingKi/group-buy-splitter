# 夾團台

計算團購（夾單）每個人要付多少錢。朋友只需輸入 Discord 名稱就可以使用，無需密碼。

## 如何運行

需要 Node.js 18 或以上版本（https://nodejs.org ）。不需要安裝其他套件。

```bash
npm start
```

然後在瀏覽器打開 http://localhost:3000 。

- `PORT`：更改端口（預設 3000）
- `DATA_FILE`：資料儲存位置（預設為 `server.js` 旁邊的 `data.json`）

想清空所有資料：停止伺服器，刪除 `data.json`，再重新啟動。

## 測試多個用戶

瀏覽器會記住登入的名稱。想同時扮演兩個人，可以用一個普通視窗加一個無痕視窗，或者按右上角的「轉換用戶」。

## 權限

| 操作 | 團長 | 團員 |
|---|---|---|
| 加入貨品（可以連價錢） | ✅ | ✅ |
| 更改貨品名稱 | ✅ | ✅ |
| 更改價錢 | ✅ 任何貨品 | 只可改自己加嘅貨品 |
| 移除貨品 | ✅ 任何貨品 | 只可移除自己加嘅貨品 |
| 加入團員 | ✅ | ✅ |
| 自己加入其他人嘅團 | — | ✅（首頁「其他夾團」→「加入呢個團」） |
| 移除團員 | ✅ 任何人 | 只可移除自己（退出） |
| 更改數量 | ✅ 任何人 | 只可改自己那一行 |
| 設定運費及分攤方式 | ✅ | ✅ |
| 查看所有總數 | ✅ | ✅ |
| 更改團購名稱、貨幣／刪除團購 | ✅ | ❌ |
| 剔「已交收」／「已付款」 | ✅ | ❌ |
| 睇「已交收」／「已付款」 | ✅ 所有人 | 只睇到自己 |
| 完結／重新開放團購 | ✅ | ❌ |

團長按「完結團購」時，如果仲有人未交收，會先顯示警告同未交收嘅名單。完結之後所有資料會鎖定，團長可以按「重新開放」再修改。

完結咗嘅團會搬去首頁嘅「封存」，保留一個月（由完結當日計），之後自動刪除。團長可以喺封存提早刪除，刪除前會有警告。重新開放會取消自動刪除。

## 計算方法

- 每人：貨品（數量 × 單價）加上分攤的運費。
- 每件貨品：總件數 × 單價。
- 全單：所有貨品加運費。
- 運費可以按貨品金額（預設）、按件數，或由有落單的人平分。每人金額計至仙位，加起來一定等於全單運費。
- 未定價的貨品在團長設定價錢前不會計入總數。

## 安全

- **通行碼**：設定環境變數 `ACCESS_CODE`，所有人登入時都要輸入呢個通行碼，冇通行碼嘅人乜都睇唔到、改唔到。只喺 Discord 入面分享，唔好公開。想換通行碼，改 `ACCESS_CODE` 再重新啟動，所有人會被登出，要用新通行碼再登入。
- **防止亂試通行碼**：同一個 IP 15 分鐘內錯 10 次就會被暫停。
- **防止洗版**：每個 IP 每分鐘最多 60 次修改；每人最多同時開 20 個團，每個團最多 100 款貨品、100 人；全站最多 3000 個用戶、1000 個團。
- **防止注入**：所有輸入都以純文字顯示，網頁亦設定咗 Content-Security-Policy，唔會執行外來嘅 script。
- 因為冇密碼，識通行碼嘅人輸入其他人嘅 Discord 名就可以用對方身份操作，所以只應該喺信任嘅朋友之間使用。

## 部署（Railway）

1. 用 GitHub 帳戶登入 https://railway.com ，New Project → Deploy from GitHub repo → 揀呢個 repo。
2. 加一個 Volume，mount path 設為 `/data`。
3. 喺 Variables 加：
   - `DATA_FILE` = `/data/data.json`（一定要設，否則每次更新都會清空資料）
   - `ACCESS_CODE` = 你自己諗嘅通行碼
4. Settings → Networking → Generate Domain，就會有網址可以分享。
5. 之後每次 `git push`，Railway 會自動更新網站，資料會保留。
